# Quantum IR Studio 1.0.170

Рабочее место для оформления химического опыта: от структуры и загрузки до
методики, полученного продукта и лабораторного отчёта.

## Установка

1. Скачайте **Quantum IR Studio-1.0.170.msi** из раздела Assets релиза.
2. Сохраните открытые опыты и закройте предыдущую версию программы.
3. Запустите MSI и следуйте мастеру установки.
4. Откройте **Quantum IR Studio** через меню «Пуск».

Комплект предназначен для **Windows x64**. Java, библиотеки и базы локального
прогноза ЯМР уже включены. Для установки отдельная загрузка зависимостей не нужна.
Установщик можно переносить на флешке. Он не подписан цифровой подписью.

## Что изменилось

### Структуры и названия

- Рисование связей перетаскиванием от атома и переключение кратности связи.
- Учёт неявных водородов, отображение формулы и расчёт молярной массы по структуре.
- Собственные названия доступны офлайн; поиск IUPAC вызывается прямо из окна имени.
- Длинные имена сокращаются на экране с сохранением полного текста.

### Проведение опыта

- Последовательный рабочий экран: реакция, загрузка, методика, наблюдения, результат.
- План и фактически внесённые количества учитываются отдельно.
- Полученный продукт и расчёт выхода доступны на вкладке «Результат».
- Наблюдения можно связывать с шагами методики; ранее выполненный шаг можно отметить
  без вымышленного времени начала.
- Молярные массы и количества рассчитываются локально. Расчёт по структуре при
  неизвестной чистоте имеет соответствующее пояснение.

### Отчёты

- Общий расчёт количества и выхода для рабочего экрана, PDF и HTML.
- Исходники показаны в таблице загрузки, продукт — в разделе результата.
- Условия имеют понятные подписи и единицы: температура, время, давление, растворитель.
- Пустые разделы скрыты, служебные подробности выключены по умолчанию.
- Улучшены ширина таблиц, переносы длинных названий и разбиение методики на страницы.

### Локальный прогноз ЯМР

- Прогноз сдвигов ¹H и ¹³C по встроенным данным nmrshiftdb2.
- Выбор растворителя, частоты прибора и состава смеси из нарисованных веществ.
- Просмотр кривой и экспорт TXT, CSV и SVG.
- Расчётные данные сохраняются отдельно от измеренных спектров.

Модель строит уширенную диаграмму химических сдвигов. Расчёт J-связей,
мультиплетов и сильной связи не включён. Прогноз не подтверждает идентичность
или чистоту полученного продукта.

## Интернет и данные

Редактор, расчёты, методика, наблюдения, отчёты и прогноз ЯМР работают локально.
Поиск названий через PubChem и получение публикаций требуют подключения.
Пользовательские опыты и личные отчёты не входят в дистрибутив и исходники релиза.

## Для разработчиков

- Java 25, Maven 3.9.9; проект состоит из модулей Java и JavaFX.
- Изменённые Java-файлы приведены к единому стилю; добавлены `.editorconfig`
  и воспроизводимая проверка форматирования.
- Форматирование проверено сравнением синтаксических деревьев: логика кода сохранена.
- Сборка Windows включает собственную Java и архив исходников с лицензиями.
- Код приложения: MPL-2.0. Лицензия и происхождение данных nmrshiftdb2
  находятся в `META-INF/quantum-nmr`.

Сборка приложения:

```bash
mvn -B -pl quantum-desktop -am package -DskipTests
```

Упаковка Windows выполняется скриптом `tools/build-windows-release.ps1`;
он принимает версию, пути к JDK, WiX 3, Java runtime и архиву исходников.
Контрольные суммы файлов релиза приведены в `SHA256SUMS.txt`.
