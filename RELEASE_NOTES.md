# Quantum IR Studio 1.0.176

## Установка по одной ссылке

**[Скачать последнюю версию для Windows x64](https://github.com/VadimKrut/quantum/releases/latest/download/quantum-ir-studio-windows-x64.msi)**

Эту ссылку можно отправить другому человеку. Он скачивает MSI, запускает мастер
установки и открывает Quantum IR Studio из меню «Пуск». Java, библиотеки и базы
локального прогноза ЯМР включены. Отдельная установка зависимостей не требуется.
Установщик не подписан цифровой подписью. Контрольные суммы — в `SHA256SUMS.txt`.

Для обновления существующей установки сохраните опыты и закройте программу.
Обычное обновление сохраняет проекты, библиотеку и настройки; удаление данных
не требуется. В версии 1.0.176 появилась кнопка «Обновления»: проверка новых
стабильных версий, скачивание с проверкой SHA-256 и запуск установки после выхода.
Автоматическую проверку можно отключить. Программа работает без интернета,
кроме загрузки обновлений и явно вызываемых внешних сервисов.

## Что изменилось с 1.0.171

- Единая навигация через «Разделы» и «Найти действие», пояснения к командам,
  сохранение выбранной стадии и понятный возврат «К серии опытов».
- Личная библиотека веществ: заметная кнопка добавления своей структуры,
  отдельные вкладки, поиск по имени и синонимам, вставка в другие опыты.
- Исправления обработчиков разделов, выбора структуры для расчётов,
  учёта продуктов стадии, форм и сообщений о результате.
- Улучшены заголовки, расположение команд и поддержка тёмной темы.
- MSI удаляет только установленные им файлы и пустые папки. Посторонние файлы
  внутри выбранной папки установки не удаляются рекурсивно.
- Интерактивное обучение со стрелками: 31 шаг основ и 45 углублённых тем.
  Практика рисования проверяет изменения схемы, отмену и повтор, кольца и вид.
  «Все функции экрана» показывает доступные команды, вложенные меню и пояснения.
- В основах и практике рисования выполненное действие переводит к следующему
  шагу автоматически. Текстовые пояснения переключаются вручную. Подсказки
  и автопереход отключаются отдельно; можно вернуться к предыдущему шагу.
- Обучение создаёт отдельные учебные файлы. Прогресс сохраняется; данные можно
  оставить для практики, удалить или начать заново. Рабочий опыт остаётся на месте.

## Проверки

Проверены форматирование изменённого Java-кода, сборка и содержимое MSI.
Локальные проверки без управления компьютером: навигация — 485 проверок,
действия — 34 сценария, обновления — 23 проверки, обучение — 676 проверок.
Учебные сценарии также прогонялись на Java и JAR из установочного комплекта.
Полного JUnit-прогона и научной валидации всех внешних расчётных движков не было.
Данные пользователя и локальные рабочие материалы в релиз не входят.

В релизе доступны установщик с номером версии, тот же MSI под постоянным именем,
архив исходников и контрольные суммы. Это первый опубликованный релиз после 1.0.171;
1.0.172–1.0.175 были локальными промежуточными сборками.

# Quantum IR Studio 1.0.171

## Исправление карточек опытов

- В списке «Проекты и опыты» миниатюра выбирается по роли «Продукт» в стадии
  реакции, даже если в общем списке вещество осталось исходником.
- Для многостадийного опыта показан первый продукт последней стадии, в которой
  задан продукт. Если стадии ещё не содержат продуктов, используется продукт
  из общего списка веществ; если продуктов нет вообще — первое вещество.
- При наведении на миниатюру можно прочитать полное название вещества.
- Исправление работает с уже сохранёнными опытами без изменения их данных.

Сборка и форматирование проверены. Автоматические тесты для этого исправления
не запускались.

Установщик: **quantum-ir-studio-1.0.171-windows-x64.msi**. Сохраните опыты,
закройте программу и установите обновление. Java включена, интернет для работы
миниатюр не требуется.

# Quantum IR Studio 1.0.170

Рабочее место для оформления химического опыта: от структуры и загрузки до
методики, полученного продукта и лабораторного отчёта.

## Установка

1. Скачайте **Quantum IR Studio-1.0.170.msi** из раздела Assets релиза.
2. Сохраните открытые опыты и закройте предыдущую версию программы.
3. Запустите MSI и следуйте мастеру установки.
4. Откройте **Quantum IR Studio** через меню «Пуск».

Комплект предназначен для **Windows x64**. Java, библиотеки и базы локального
прогноза ЯМР уже включены. Для установки отдельная загрузка зависимостей не нужна.
Установщик можно переносить на флешке. Он не подписан цифровой подписью.

## Что изменилось

### Структуры и названия

- Рисование связей перетаскиванием от атома и переключение кратности связи.
- Учёт неявных водородов, отображение формулы и расчёт молярной массы по структуре.
- Собственные названия доступны офлайн; поиск IUPAC вызывается прямо из окна имени.
- Длинные имена сокращаются на экране с сохранением полного текста.

### Проведение опыта

- Последовательный рабочий экран: реакция, загрузка, методика, наблюдения, результат.
- План и фактически внесённые количества учитываются отдельно.
- Полученный продукт и расчёт выхода доступны на вкладке «Результат».
- Наблюдения можно связывать с шагами методики; ранее выполненный шаг можно отметить
  без вымышленного времени начала.
- Молярные массы и количества рассчитываются локально. Расчёт по структуре при
  неизвестной чистоте имеет соответствующее пояснение.

### Отчёты

- Общий расчёт количества и выхода для рабочего экрана, PDF и HTML.
- Исходники показаны в таблице загрузки, продукт — в разделе результата.
- Условия имеют понятные подписи и единицы: температура, время, давление, растворитель.
- Пустые разделы скрыты, служебные подробности выключены по умолчанию.
- Улучшены ширина таблиц, переносы длинных названий и разбиение методики на страницы.

### Локальный прогноз ЯМР

- Прогноз сдвигов ¹H и ¹³C по встроенным данным nmrshiftdb2.
- Выбор растворителя, частоты прибора и состава смеси из нарисованных веществ.
- Просмотр кривой и экспорт TXT, CSV и SVG.
- Расчётные данные сохраняются отдельно от измеренных спектров.

Модель строит уширенную диаграмму химических сдвигов. Расчёт J-связей,
мультиплетов и сильной связи не включён. Прогноз не подтверждает идентичность
или чистоту полученного продукта.

## Интернет и данные

Редактор, расчёты, методика, наблюдения, отчёты и прогноз ЯМР работают локально.
Поиск названий через PubChem и получение публикаций требуют подключения.
Пользовательские опыты и личные отчёты не входят в дистрибутив и исходники релиза.

## Для разработчиков

- Java 25, Maven 3.9.9; проект состоит из модулей Java и JavaFX.
- Изменённые Java-файлы приведены к единому стилю; добавлены `.editorconfig`
  и воспроизводимая проверка форматирования.
- Форматирование проверено сравнением синтаксических деревьев: логика кода сохранена.
- Сборка Windows включает собственную Java и архив исходников с лицензиями.
- Код приложения: MPL-2.0. Лицензия и происхождение данных nmrshiftdb2
  находятся в `META-INF/quantum-nmr`.

Сборка приложения:

```bash
mvn -B -pl quantum-desktop -am package -DskipTests
```

Упаковка Windows выполняется скриптом `tools/build-windows-release.ps1`;
он принимает версию, пути к JDK, WiX 3, Java runtime и архиву исходников.
Контрольные суммы файлов релиза приведены в `SHA256SUMS.txt`.
